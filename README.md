# Deadline and Date Formatter

## Project Description
The Deadline and Date Formatter is a simple Python program that collects event details and displays the deadline in a clear and readable format.

It uses Python's datetime module to format dates and identify the weekday of an event.

## Program Features
- Accepts the event title.
- Accepts the event year.
- Accepts the event month.
- Accepts the event day.
- Converts the event title into uppercase.
- Displays the complete date in a readable format.
- Displays the year, month, and day separately.
- Identifies the weekday of the event.

## Programming Language
Python

## Library Used
`datetime`

## Date/Time Features Used
- `datetime()` - Creates a date using the given year, month, and day.
- `strftime()` - Formats the date into a readable format.
- `strftime("%A")` - Gets the weekday name.
- `strftime("%B")` - Gets the month name.
